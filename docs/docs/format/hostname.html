Format.IsHostname

Returns true if the string is a hostname conforming to RFC 1123, with internationalized domain names supported by RFC 5891, RFC 5892, and RFC 5893.

Function

Test with format function

import Format from 'typebox/format'

const R = Format.IsHostname('example.com')

Schema

Test with format keyword

import Schema from 'typebox/schema'

const R = Schema.Check({ format: 'hostname' }, 'example.com')
